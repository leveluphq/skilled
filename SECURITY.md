# Security policy

## Reporting a vulnerability

Please report security problems privately. Don't open a public issue or pull request for them.

- Use GitHub's private vulnerability reporting: open this repository's **Security** tab and choose **Report a vulnerability**.
- Or email hey@skilled.dev.

Say what you found, where it is, and how to reproduce it. We'll reply once we've looked at it.

## Scope

This policy covers the code in this repository and the site it runs, [skilled.dev](https://skilled.dev).

If you run your own copy, you're responsible for its settings and secrets. [docs/README.md](docs/README.md) describes them, including which ways of running learners' code are safe to expose to other people.
