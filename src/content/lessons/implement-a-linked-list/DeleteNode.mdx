<SubsectionHeader>Delete a Node</SubsectionHeader>

To delete a node, first we find the node that precedes it in the linked list.
Then we change this preceding node's `next` <ConceptModal content={<PointersConcept />}>pointer</ConceptModal>
to reference the node after the one we want to delete (`precedingNode.next = precedingNode.next.next`).
Since none of the items in the linked list reference the node we wanted to delete anymore, it is effectively removed from our linked list.
In languages with a garbage collector (JavaScript, Python, Java, C#, Go, Kotlin), the collector notices that nothing references the node and frees its memory.
Swift frees it as soon as its last reference goes, Rust frees it when its owner goes out of scope, and in C++ we `delete` it ourselves.
