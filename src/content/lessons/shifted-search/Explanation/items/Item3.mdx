Our approach is reasonably simple.

1. Determine if the half to the left or right of the midpoint is ordered correctly from smallest to largest (does not have the rotation).
2. Determine if the target number is between the smallest or largest value in the correctly-ordered half. This comparison will let us know which half (either right or left) the target must exist in.
3. Update either the start or end bound to encompass the half that we know our target must be contained in. This is analogous to how we update the start or end to the midpoint item in a standard binary search.
