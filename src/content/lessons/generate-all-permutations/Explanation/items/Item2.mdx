We want to generate all the options, and this is an indication we will use recursion and specifically backtracking.
Take a character from the decision space, which is each of the characters at each depth of the recursive call, and then pass the remaining items recursively.

No matter how large the string gets, it can be reduced to this simple and repeatable problem at each level.

1. Take a character and treat it as the choice for each decision step
2. Remove this character from the string and pass the remaining characters recursively
3. Remove a new decision character at each lower depth until you only have one character remaining at the base case
4. Repeat for every character at every depth and combine the results
