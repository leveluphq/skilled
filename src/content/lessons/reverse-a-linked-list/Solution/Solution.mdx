You have three pointers — to the previous, current, and following node.
To reverse the list, at each item you set the current node's `next` pointer to the previous node.
Then you move each pointer forward and repeat the process for every item.


1. Set the temporary variable to point to the current node's `next` item
2. Now set current node's `next` pointer to the previous node (this is where the reverse happens)
3. Move the previous node forward to now point to the current node
4. Move the current node forward to point to the node after it that we stored in the temporary variable
