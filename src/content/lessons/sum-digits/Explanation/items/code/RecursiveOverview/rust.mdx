```rust
sum_digits(n) = n % 10 + sum_digits(n / 10) // recurse while n > 0

// recursive order (divide integer by 10 each step)
sum_digits(6321) + sum_digits(632) + sum_digits(63) + sum_digits(6) + sum_digits(0)
// 6321 % 10    +    632 % 10    +    63 % 10    +     6 % 10   + (base case)
//     1        +       2        +       3       +       6      +      0
```
