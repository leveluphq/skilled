This problem can be solved by decomposing the input integer to each digit and shifting it to the ones place by repeatedly dividing the number by 10.
To extract the digit in the ones place, we take the modulo `% 10` of it to determine its value.
We recursively divide by 10 and take the modulo of 10 until the input number reaches 0 which is the base case.

<ComplexitySubtitle />

<p>
  <BigO.n letter="d" /> time and <BigO.n letter="d" /> space where <code>d</code> is the number of digits in the input.
</p>

The time and space complexity of this question is very interesting.
Typically we need to account for the time to iterate through the entire input and the space required to build the stack for a recursive solution.

Here the input is a single integer, so its size is measured by its number of digits `d`.
We make one recursive call for each digit, so both the time and the call stack grow with `d`.
Since an integer `n` has about `log10(n)` digits, you can also describe this as <BigO.logn /> where `n` is the value of the input.

It's tempting to call this <BigO.constant /> because a 64-bit integer has at most 20 digits,
but Python integers have no maximum value, so the number of digits can grow arbitrarily large.
Give your answer in terms of the number of digits.
