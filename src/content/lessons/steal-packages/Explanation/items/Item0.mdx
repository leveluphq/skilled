Approaching this problem, candidates usually have one of two mindsets:

1. It's easy because you can just skip every other house and sum them (which we'll see is not true).
2. It's difficult because there are an intimidating number of combinations of packages, especially with a large input.

The answer is actually somewhere in between these two mentalities.
Let's start by investigating the input data and build up from the most simple examples we can think of.

Our input array contains the value of packages, so it's reasonable to assume they are all positive numbers.
A negative number would mean we pay money to take the package which would never happen.

With the most simple case, we would have an empty array which means we would just return `0`.
If there is an array with one item, we return that value.
