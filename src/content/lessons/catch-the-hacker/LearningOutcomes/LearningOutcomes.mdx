Many interview questions build on the concepts learned here.
Always think back to the hash table section when you are looking to optimize your solution.

- We used a hash table to get fast constant time <BigO.constant /> lookups.
- We learned how to extract the important information from a problem told as a story.
- The baseline assumption is that a hash table will cost <BigO.n /> space.
- We learned how to iterate a hash table.
  It is common to need to do this in an interview.
  During interviews I have conducted,
  when I asked similar problems that required this hash table iteration,
  it was surprising to see how many people could create a hash table,
  talk through the logic to solve the problem,
  but weren’t able to complete the code without help because they didn’t understand how to iterate the table's properties.
