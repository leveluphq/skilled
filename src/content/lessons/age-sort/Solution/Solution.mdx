This question is a special case for sorting.
Typically with questions that require sorting, the input data can be arrays containing arbitrary numerical values or string values.

However, here we have a well-defined range of values for the input that we know beforehand.
Using this information, we can bucket the items based on this value to count their total number of occurrences.

Once we have the count of all the ages for each bucket, we start at the lowest age and add it to the output array based on its count.
After doing this for all 101 valid ages, we will have a completely sorted solution.
