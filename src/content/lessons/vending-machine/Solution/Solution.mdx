This question can be solved using a bottom-up dynamic programming solution.
To calculate the solution, we start at `0` and find the minimum number of coins to make change for all the amounts up to our `target`.

We can solve this by using a combination of subproblem solutions.
At each step, we find the minimum number of coins to make change for every `amount` from `0` to the `target` by trying each denomination at each value.
We subtract a coin's value to "look back" to check if there was a previously calculated minimum that we can add this coin's value to which would reach the current `amount`.
We use an array to store the results to subproblems and track the minimum coins required for all change values up to the `target`.
