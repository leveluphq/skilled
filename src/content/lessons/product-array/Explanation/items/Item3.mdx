To construct our array for the product of the left elements, we start at index zero and get the running left product by taking the current integer and multiplying it by the running product calculated at the previous index.

For the running product of the elements to the right, we actually want to start at the end of the array at `length - 1` and work backward to the beginning.

For the starting points in each array, we don't have a running product to begin with, so instead we initialize it to 1 because `any_number x 1 = any_number`.
So with `results[0]`, this means we would multiply 1 with the running product of all the items to the right.
The same goes for our last element. It would be 1 times the running product of all the items to the left.
