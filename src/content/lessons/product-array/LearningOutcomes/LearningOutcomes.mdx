Sometimes questions put constraints on how we solve it to mimic limiting factors that could arise in real scenarios.

For example, maybe the code could be executed on a remote server that has memory constraints.
If you load a lot of data into that server and don't consider this, you could crash it.
In an even more complex question, you could be so resource-constrained that you query data into chunks instead of loading it all into memory.

The important thing is to make sure you understand the question and its constraints, and that you answer exactly what is being asked.
