In JavaScript, functions are first-class citizens, which means they can be treated like any other data type.
A function can be assigned to a variable, passed as an argument to another function, or be the return value from another function.

An anonymous function means we use a function without declaring or naming it.
The most common example of this in JavaScript is a callback function where we pass an anonymous function as an argument to be executed inside another function.

If a variable is declared in the global scope, it is available to all the code in an app, which can cause collisions and difficult bugs.
JavaScript is a function-scoped language which means that variables declared in a function will only exist in that function.
Anonymous functions declared as <a href="https://developer.mozilla.org/en-US/docs/Glossary/IIFE" target="_blank" rel="noopener noreferrer">IIFEs</a> would allow us to run code without polluting the global scope.
