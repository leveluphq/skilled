This problem can be solved by iterating over the input string once.

Every opening bracket must have a matching closing bracket.
So when we encounter a closing bracket, we check the most recently seen opening bracket.
Once the pair is validated we can then set them aside and check each additional pair.
We achieve this by using a stack.

We initialize a stack and begin iterating through the string.

- If a character is an opening bracket, we `push` it to the stack.
- If a character is a closing bracket, we `pop` the stack and compare the last seen opening bracket to this closing bracket.
  If they don't match or the stack was empty, we return false.
- Once we finish iterating through the input string, we check if any items remain in the stack. If it is empty, we know all brackets matched, and it will return true.
