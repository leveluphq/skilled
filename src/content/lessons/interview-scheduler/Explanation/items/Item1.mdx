By thinking through these simple examples, we discovered the foundation of our algorithm.
**You walk through the array of meeting times, and if the start time comes before the end time of the currently tracked interval, we include it in this combined interval**.

Specifically what we're doing is checking the start time of the current meeting against the end time of some aggregated interval.
When we combine a meeting with an interval, if the newly added meeting's end time comes after the combined interval's end time, the combined interval's end time is updated to be the latest end from this new meeting.
