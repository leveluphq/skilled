This question can be solved using a bottom-up dynamic programming solution.
We build a table where each row adds one more item and each column is a weight limit from `0` up to the `capacity`.
Each cell is a decision: we either skip the current item and keep the best value from the row above,
or we take the item and add its value to the best value the row above found for the weight that is left over.
Since we only look at the row above, each item is used at most once.
Once we have tried every item at every weight, the last cell holds the answer.
