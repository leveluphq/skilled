We use the runner technique with two pointers that both start at the `head`: `slow` moves one node at a time, and `fast` moves two.
If there is no loop, `fast` reaches the end of the linked list.
If there is a loop, `fast` can never reach the end, so it keeps going around the loop until it lands on the same node as `slow`.
We check that the two pointers are the same node instead of comparing their `data`, because different nodes can have the same `data`.
