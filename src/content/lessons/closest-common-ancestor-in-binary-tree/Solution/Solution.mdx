In this question, we are doing a recursive post-order traversal.
We traverse the `left` and `right` paths before we handle the result at any given node, so we know that we will have accounted for all the nodes below the current one.

When we reach one of the target input values, we return this node.
Once all the recursive calls return to any given node,
if both the return values are not <Null /> (they contain a node), we know that we have reached the common ancestor and return this node.
This node will propagate up until all the recursive calls unwind.

In this problem, we have two base cases:

1. Reaching a <Null /> value (target not found on this path)
2. We reach one of the input targets (return this node)

Since we return values that are not <Null />, this will send valid values up and eventually produce the solution.
