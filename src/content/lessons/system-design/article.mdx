MAY NEED A NEW PROBLEM TEMPLATE FOR SYSTEM DESIGN. Break decisions into sections.

System design questions are very different than algorithms and data structure.

- With algorithmic questions, the goal is to write code that will yield the correct answer.
- With system design, the goal is to create a discussion.

The way system design questions are presented is that the interviewer will ask the technical decisions you would make to build something for the real world.
For example:

- Design a social network
- Design the Yelp API
- Design a video platofrm like YouTube

Because there isn't a "right answer" for system design, some developers find theme easy while others can feel they are overwhelming.
The good news is that the way you're judged is very much based on experience.
Since the goal is to understand how you approach problems in the real-world,
the expectation is that people who have worked longer should know more.

This module will show you how to approach system design questions,
and give lay out a plan so you'll gain the experience you need to perform at the top-end of your experience level.
