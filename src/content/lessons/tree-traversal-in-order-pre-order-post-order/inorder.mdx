### In-Order Traversal

In-order traversal is the most common and visits a node's left subtree, then the node itself, and then its right subtree.
If it were a binary search tree, this visits the nodes in ascending order, starting with the smallest value at the left-most node and ending at the largest value at the right-most node.

Use in-order traversal on a BST if you need to utilize the nodes as if they are in a sorted linear order.
