To know the maximum depth, all we need to do is track the current maximum in a variable and compare it to each node's depth.
If we encounter a node that has a larger depth, we replace the current maximum.
Since we are traversing through all `n` nodes, once we finish iterating, the value stored in the current maximum will correspond to the tree's overall maximum depth.
