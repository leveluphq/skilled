To look for improvements, let's first understand the assumptions we can make about the data.
Numbers are always increasing along any given row or column.

If we take a matrix and pick different targets, let's see what intuition we can gain from that.

We know that going right or going down from any given point must be ascending values based on the question prompt.
If we consider an arbitrary point in the matrix, everything in the down-right direction must be larger than this item.
It creates a box of values that all must be larger for all of the items that are both down and right from this point.

For up and left, the opposite is true, and all values must be smaller in both directions which creates a box of all smaller values.
If we consider an arbitrary point in the matrix, everything in the up-left direction must be smaller than this item.

But what about values down-left or up-right?
This mixes the logic, so values can be either smaller or larger.
What I mean by this is that up is smaller and right is larger, so up-right is unknown.
The same can be said for down-left.
We can't make any assumptions about the data in these quadrants.
