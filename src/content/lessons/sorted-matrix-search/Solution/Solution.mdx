We recognized that at any item, all the values up and left must be smaller, and all the values down and right must be larger.
This means that if we start at the bottom-left item, we can iterate inward and give ourselves a decision with two options that can eliminate an entire row or column on every comparison.

Our solutions follows the logic:

1. Start at the bottom-left node and compare it to the target value.
  If the target is larger then move right, and if the target is smaller then move up.
2. If the traget is found at any step, return the coordinates.
3. If the target is not found, compare the current value to the target and move either up or right.
4. If you reach either the top edge or right edge, you have run out of moves, and the value doesn't exist in the matrix.
  Return the coordinates as `[-1, -1]`.
