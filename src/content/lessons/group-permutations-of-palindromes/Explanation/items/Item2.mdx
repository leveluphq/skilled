First we create a hash table that tracks the count of each character in a string.

Then we iterate through all the character counts in our hash table and increment a counter every time we see an odd number.
If we have 0 or 1 odd number character counts, we return true and otherwise false.

<HashTableStorage />

All the operations are linear time and space, so the function itself is <BigO.n letter="c" /> where `c` is the number of characters in an arbitrarily large string.
When we use this function for all `n` words in our list, that will be <BigO.n letter="n x c" />.
