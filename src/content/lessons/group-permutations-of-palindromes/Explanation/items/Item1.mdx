First we will determine if a string is a permutation of a palindrome.
A palindrome means a string is the same forward and backward,
and we want to know if _any arrangement_ of a string's characters can form a palindrome.

The brute force way to generate all permutations for a string is <BigO.factorial letter="c" /> where `c` is the number of characters in the string.
Then we would need to check if each permutation is a palindrome.
There has to be a better way.

Let's think about what knowledge we can gain from the definition of a palindrome.
If a palindrome is the same forward and backward, then if we split the palindrome in half,
it would contain the same number of the individual letters in each half.

<Container>

```javascript
n      o     |     o      n
n x 1, o x 1 | o x 1, n x 1   = n x 2, o x 2
```

</Container>

So we could say the total number of characters in a palindrome is `2x` the characters of half the palindrome.
Any number multiplied by 2 is an even number.
Therefore, a string could form a palindrome if there are an even number of characters for the entire string.

<Container>

```javascript
noon => n x 2, o x 2
sees => s x 2, e x 2
btrttrtb => b x 2, t x 4, r x 2
```

</Container>

This is almost exactly true, except if our string has an odd number of characters.
Then the middle character of the palindrome will appear only once, but every other character will appear an even number of times.

<Container>

```javascript
racecar => r x 2, a x 2, c x 2, e x 1
zzprprpzz => z x 4, r x 2, p x 3
```

</Container>

So we can say a string is a permutation of a palindrome if all but one character appear in a string an even number of times.
One character is allowed to appear an odd number of times and our string can still form a palindrome.
