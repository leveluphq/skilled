## Read constraints before matching a pattern

A sorted pair-sum problem with constant auxiliary space suggests two pointers. Remove the sorted-input guarantee and that elimination proof disappears. A hash map can handle unsorted values in expected linear time, but uses additional space. Choosing between them requires reading both the input and memory requirements.

A contiguous sum target does not automatically imply a sliding window. Negative values can reduce an oversized sum after a start has been discarded. Prefix sums with a frequency map can count matching signed subarrays because the method tracks earlier cumulative totals rather than assuming sums move in one direction.

Likewise, “shortest path” needs an edge-cost qualification. BFS gives fewest-hop paths in an unweighted graph. If edges have different nonnegative weights, counting queue layers is insufficient to minimize total weight. The quiz's graph prompt deliberately says every edge counts as one hop.

## Check what an answer must return

Finding any matching value differs from finding its first position. When duplicate values exist, returning immediately on an equal binary-search midpoint can produce a valid match without producing the requested boundary. A lower-bound search keeps equality as a possible upper boundary and continues left.

Generating every subset differs from returning a count or an existence answer. Materializing the outputs has exponential cost, and each saved path needs an independent array. A method that quickly identifies one large-sum subset cannot satisfy a request for every subset.

For the K largest arrivals in a stream, the heap must expose the weakest retained candidate. A min-heap does that even though the desired output contains large values. The result can be the right multiset without being sorted. State whether output order is part of the contract before adding a final sort.

## Turn missed questions into focused exercises

After a prefix-sum miss, trace `[0, 0]` with target zero. Distinguish the three nonempty intervals and identify which earlier zero boundary supplies each one. After a stack miss, trace `[70, 70, 71]` and explain why equality must remain unresolved for a strictly warmer answer.

After a DP miss, compare taking the largest value in `[4, 5, 4]` with taking both outside values. Write the recurrence in terms of skipping or taking the current position, then test an all-negative input when an empty selection is allowed. After a backtracking miss, mutate one returned subset and check whether another result changes.
